# Database

Отдельный публичный репозиторий `egorovdnikita/skill-database` для навыка Database. Источник — `SKILL.md`. Его используют Claude Chat и настольный ChatGPT на Mac. Синхронизация изменяет только этот навык; второй хранится в отдельном репозитории. Персональные сведения, CONTEXT.md, life.db, переписки и резервная выжимка Database в git не входят.

## Что синхронизируется

- `python3 scripts/sync-skills.py sync` получает main из GitHub, сравнивает общие файлы с локальными synced-копиями Claude, фиксирует и отправляет изменения. Затем обновляет локальные зеркала и пакеты `.skill`.
- При разных изменениях обеих сторон публикация останавливается. Скрипт не выбирает победителя и не выполняет принудительный push. При сетевой ошибке сообщает неуспех и повторяет push на следующем запуске.
- `python3 scripts/sync-skills.py status` показывает состояние без сетевых запросов и записи.
- `python3 scripts/sync-skills.py init` сохраняет базу версий только при полном совпадении локальных файлов.

Синхронизация Mac каждые 30 минут выполняет `sync`, а не простой pull. Компьютер должен быть включён и иметь доступ к GitHub по SSH. Скрипт проверяет типовые секреты и почты, но это не замена проверки приватности агентом перед коммитом.

## Изменения из ChatGPT

1. Выполнить sync до правки. Если есть конфликт — сначала объединить правки.
2. Изменить общий исходник, проверить приватность и выполнить sync ещё раз.
3. Создать пакет: `python3 scripts/sync-skills.py export database` для этого навыка.
4. Обновить существующий навык в Claude Chat: Настройки → Плагины → навык → … → Загрузить новую версию. Выбрать соответствующий `.skill`, загрузить и проверить версию.

Шаг 4 агент может выполнить через разрешённый браузер. Фоновая задача Mac НЕ управляет облачным интерфейсом Claude. Если шаг 4 не выполнен, нужно прямо сообщить, что Claude Chat ещё не обновлён.

## Изменения из Claude Chat

Сначала сверить установленную версию с GitHub. Правку делать штатным редактором Claude и сохранить. После появления новой версии в synced подключить этот репозиторий с правом записи и запустить `scripts/sync-from-claude.sh`. Пакеты содержат `references/sync-base.json`: если GitHub изменился с момента установки пакета, публикация останавливается. Параллельные правки нужно объединить, затем загрузить новый пакет.

После публикации загрузить свежий пакет и проверить его версию, чтобы обновить версию-основание. Перенос сохранённых облачных файлов в synced на Mac зависит от приложения Claude; наличие локального каталога не доказывает постоянную облачную синхронизацию.

## Приватная часть Database

Резервная выжимка хранится только в `~/.local/share/shared-agent-skills/database-private-context.md`. Экспорт Database при наличии этого файла включает её в `references/private-context.md` для приватной загрузки в прежний аккаунт Claude. Git её не получает. Обновление инструкции навыка не обновляет автоматически личные данные.

В этом же локальном каталоге находятся база хешей, блокировка, резервные копии и экспорты. Пакеты Database не коммитить. Оригинальные локальные файлы сохранены перед подключением общей схемы.
